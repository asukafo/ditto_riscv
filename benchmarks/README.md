# 公共性能基准

此目录保存跨版本比较专用的汇编程序，由 [比较器](../tools/benchmark.py)分别在各版本工作目录编译。
比较器检查两版二进制哈希相同，然后执行独立参考校验。

| 文件 | 用途 | RAM 0x200 预期结果 |
|---|---|---:|
| independent.S | 四组累加器的直线 ALU 运算 | 640 |
| compressed.S | RV64C 压缩指令依赖链 | 128 |

其余求和、指针追踪、访存和 C 基准使用各版本 `sw/` 中保存的软件快照。
程序通过各版 `sw/finish.inc` 中的退出邮箱协议结束。
新增基准时应明确预期结果、输入数据与编译选项，并记录到比较器的程序列表中。
