# 公共性能基准

此目录保存跨版本比较专用的汇编程序，由 [比较器](../tools/benchmark.py)分别在各版本工作目录编译。
比较器检查两版二进制哈希相同，然后执行独立参考校验。

| 文件 | 用途 | RAM 0x200 预期结果 |
|---|---|---:|
| independent.S | 四组累加器的直线 ALU 运算 | 640 |
| compressed.S | RV64C 压缩指令依赖链 | 128 |
| data_reuse.S | 重复128次读取同一个8字节数据，观察数据局部性 | 896 |
| calls.S | 16次函数调用/返回，观察返回预测 | 64 |
| paged_loop.S | 开启Sv39的同页取指/数据循环，观察TLB和页表读取 | 448 |

其余求和、指针追踪、访存和 C 基准使用各版本 `sw/` 中保存的软件快照。
程序通过各版 `sw/finish.inc` 中的退出邮箱协议结束。
新增基准时应明确预期结果、输入数据与编译选项，并记录到比较器的程序列表中。

新增动态分支对照：`branch_forward.S`（向前恒跳）、`branch_phase.S`（方向分阶段变化）、`branch_alternating.S`（交替方向）、`branch_alias.S`（相同BHT索引的相反方向）。它们与旧版本执行同一二进制，分别保留改善与退步项。

`branch_correlated.S`让相邻条件分支共享同一个条件，比较独立计数与全局历史的效果；期望累加结果64。
